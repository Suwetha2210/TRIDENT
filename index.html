How it works

Three layers, each catching what the previous one misses. Cheap filters handle easy cases — the expensive transformer handles the hard ones.

01
Heuristic detection
regex · pattern matching
18 hand-crafted patterns cover known attack signatures — "ignore previous instructions", DAN-style jailbreaks, data exfiltration commands. Zero compute, sub-millisecond speed. Perfect precision — zero false alarms.
63.4% accuracy
02
Random Forest
TF-IDF · scikit-learn · LIME
TF-IDF converts each prompt into a 5000-dimensional word-importance vector. A 100-estimator Random Forest classifies it. Catches statistical patterns that exact-phrase rules miss. LIME explains which words triggered detection.
93.6% accuracy
03
DistilBERT
HuggingFace · PyTorch · T4 GPU
Fine-tuned on the deepset prompt-injection dataset for 3 epochs. Understands full sentence semantics — catches paraphrased and disguised attacks that bypass layers 1 and 2 by reusing benign-sounding vocabulary.
96.8% accuracy
